feat: scrape all scheme data from myscheme.gov.in

Root Cause Analysis (RCA)

1. Interactive Tab Rendering on MyScheme:
   `myscheme.gov.in` uses dynamic Next.js component tabs (`Details`, `Benefits`, `Eligibility`, `Application Process`, `Documents Required`, `Frequently Asked Questions`). When a scheme URL loads, only the `Details` tab text is rendered in the DOM. The text for `Benefits`, `Eligibility`, `Application Process`, and `Documents` is loaded dynamically only when a user actively clicks on `<span class="...whitespace-nowrap...">` tab headers. Previous scrapers failed because they simply read the initial static body text without dispatching tab-click events.

2. Archived / Removed Slugs on MyScheme:
   Certain older scheme slugs in the dataset return `"Something went wrong. Please try again later."` directly on `myscheme.gov.in` because the portal archived, merged, or removed those endpoints from their live database.

---

 Solution Implemented

1. New Interactive Web Scraper (`scrape_all_govt_schemes_tabs.py`):
   - Developed a new script located at [`fastapi_backend/scripts/web_scraping/scrape_all_govt_schemes_tabs.py`](file:///D:/MCA%20Sage%20Uni/Semester-3/Project%20Ideas/ArogyaMitra/fastapi_backend/scripts/web_scraping/scrape_all_govt_schemes_tabs.py).
   - Operates via headless SeleniumWebDriver to navigate to scheme pages, dynamically click every interactive tab element, and slice the rendered body text between the tab header list and the footer.

2. Regex NLP Text Extraction Fallback:
   - For archived/removed slugs that return error pages on the live website, we applied a regex text parser across the scheme's existing `Description` and `BriefDescription` fields.
   - Sifted out relevant sentences using keyword regex patterns for `Benefits` (`subsid`, `assist`, `grant`, `stipend`, `₹`, etc.), `Eligibility` (`eligib`, `resident`, `applicant`, `income`, etc.), `ApplicationProcess` (`apply`, `portal`, `form`, `submit`, etc.), and `Documents` (`aadhaar`, `proof`, `certificate`, `photo`, etc.).
   - Synthesized structured metadata fallbacks for any remaining ambiguous fields.
