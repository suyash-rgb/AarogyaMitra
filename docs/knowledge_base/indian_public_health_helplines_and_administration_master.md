## 5. RAG Retrieval Architecture & Guardrail Guidelines

### A. High-Acuity Zero-Shot Fallback Rules
To prevent unsafe algorithmic latency or stochastic LLM hallucinations during life-critical encounters, the ArogyaMitra conversational engine enforces deterministic guardrail checks at the system prompt layer:

1. **Immediate Crisis Trigger Detection:** Queries containing explicit tokens for imminent self-harm (*"suicide"*, *"want to die"*, *"end my life"*), severe violence (*"domestic abuse"*, *"being beaten"*), acute poisoning (*"pesticide swallowed"*, *"snake bite poison"*), or severe trauma (*"major accident"*, *"unconscious bleeding"*) bypass general vector search.
2. **Deterministic Response Generation:** The engine immediately returns hardcoded, pre-validated UI cards displaying the relevant statutory helpline numbers (e.g., Tele-MANAS `14416` / AASRA `9820466726` for suicide, ERSS `112` / EMS `108` for trauma, NPIC `1800-116-117` for poison, Women Helpline `181` for abuse) alongside direct click-to-call action triggers.

### B. Vernacular & Transliterated Query Expansion
Users in rural and semi-urban India frequently use colloquial Hindi/Hinglish terms or regional titles when querying administrative roles and facilities. Embeddings and pre-retrieval query rewriting MUST expand the following vernacular synonyms:

* **Tehsil / Sub-district Hospital:** *"tehsil hospital"*, *"taluka dawkana"*, *"bada sarkari aspatal"*, *"bada clinic"* -> Maps to `SDH` / `CHC`.
* **Grassroots Nurse / Vaccinator:** *"nurse didi"*, *"tika didi"*, *"sub-center wali"*, *"suie didi"* -> Maps to `ANM`.
* **Village Health Activist:** *"asha didi"*, *"gaon ki asha"*, *"delivery wali didi"* -> Maps to `ASHA`.
* **Village Child Care Centre:** *"khichdi ghar"*, *"baccho ka center"*, *"pohaa center"* -> Maps to `AWW / Anganwadi`.
* **Senior Medical Officer:** *"babu doctor"*, *"bada doctor"*, *"sarkari doctor incharge"* -> Maps to `BMO / CMHO`.
* **Free Medicine / Diagnostics Centre:** *"arogya mandir"*, *"dawa ghar"*, *"sarkari clinic"* -> Maps to `Ayushman Arogya Mandir (AAM)`.

### C. Federated Metadata Filtering
Because emergency ambulance dispatch (108/102) and general medical tele-triage (104) are administered at the State / UT level, vector database records MUST include strict metadata key-value tags (`jurisdiction: "National"` vs `jurisdiction: "State-Specific"`). User session location metadata (detected state or user choice) should automatically filter candidates to prevent presenting out-of-jurisdiction contact information.
