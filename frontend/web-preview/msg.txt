WhatsApp Web Desktop SPA Simulation

Summary of Features Built:
1. Desktop 2-Pane Split View Layout:
   - Left Sidebar with user avatar (`Leo (You)`), state/language badges, search bar, quick filter tabs (`All`, `Unread`, `Favorites`, `Groups`), and chat list with verified badges & audio previews.
   - Right Chat Area with WhatsApp background wallpaper pattern, active contact header, call trigger, and default welcome view.
2. Specialized Healthcare Widgets & Micro-Interactions:
   - Custom WhatsApp Markdown text formatter (`*bold*`, `_italic_`, `~strikethrough~`, lists).
   - Quick Action Reply Buttons (rounded green outline pills).
   - Horizontal Doctor Tele-consultation Carousel & ABHA Appointment Confirmation Ticket.
   - Nearby Hospital/PHC Locator Cards with Google Maps navigation links.
   - Government Healthcare Schemes Carousel (Ayushman Bharat PM-JAY, PMSMA, MJPJAY, JSY).
3. Modals & Drawers:
   - 7-Tab Scheme Detail Modal (Overview, Benefits, Eligibility, Documents, Process, FAQs, References + Share).
   - Language Selection Modal (10 Indic Languages).
   - State Selection Modal (36 States & UTs).
   - Contact Profile Drawer with Chat Lock, Auto-Translate, and full-screen avatar view.
   - Right-click / Long-press Context Menu (`Copy`, `Forward`, `Share`).
4. Voice Messaging & Audio Effects:
   - Voice Recording bar with live timer, animated waveform visualizer, pause/resume, and send audio note.
   - Playable Audio Message bubbles in chat wall.
   - Web Audio API notification sound effect when incoming bot messages arrive.
